# ArtConnect - Artwork Analysis

ArtConnect is a web application that uses computer vision and machine learning to analyze artworks and provide valuable information about their style, potential market, and marketing strategies.

## Features

- 🎨 Automatic artistic style classification
- 👥 Market analysis and potential customer profiles
- 💰 Price estimation based on visual features
- 📈 Marketing strategy recommendations

## Requirements

- Python 3.8+
- Dependencies listed in `requirements.txt`

## Installation

1. Clone the repository:
```bash
git clone [REPOSITORY_URL]
cd ArtConnect
```

2. Install dependencies:
```bash
pip install -r requirements.txt
```

3. Run the application:
```bash
streamlit run app.py
```

## Deployment

The application is designed to be deployed on platforms such as:
- Streamlit Cloud
- Hugging Face Spaces
- Vercel
- Render

## Technologies Used

- Streamlit for web interface
- PyTorch and TorchVision for image analysis
- Transformers for text analysis
- Scikit-learn for data analysis
